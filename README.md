# 🏡 Airbnb Market Analysis

Interactive Power BI dashboard analyzing Airbnb listings and customer reviews to identify pricing trends, booking patterns, and business opportunities.

---

## 📖 Project Overview

This project explores Airbnb data using Power BI. The goal was to transform raw data into an interactive dashboard that helps understand pricing, customer behavior, and market performance.

---

## 🎯 Business Questions

- Which neighborhoods have the highest average prices?
- Which room types generate the highest revenue?
- How are listings distributed across neighborhoods?
- How do customer reviews change over time?

---

## 🛠 Technologies

- Power BI
- Power Query
- DAX
- Excel

## 📈 Key Insights

- Entire homes have the highest average prices.
- Several neighborhoods consistently outperform others.
- Review activity varies by season.
- Interactive filters allow users to explore the data dynamically.
